# Frontline Tactics — نبرد فرماندهان

یک بازی استراتژی هم‌زمان (RTS) سه‌بعدی و تک‌نفره برای مرورگر؛ ساخته‌شده با Three.js و Vite. همهٔ مدل‌های میدان در خود برنامه و با هندسه‌های ساده ساخته می‌شوند و بازی به هیچ فایل گرافیکی یا صدای خارجی وابسته نیست.

## چه چیزهایی در بازی هست

- **شروع از صفر**: هر نبرد با زمین خالی و ۶٬۰۰۰ اعتبار آغاز می‌شود؛ اول مرکز فرماندهی را می‌گذاری و بعد پایگاه را مرحله‌به‌مرحله بالا می‌بری.
- **درخت پیشرفت واقع‌گرایانه**: مرکز فرماندهی ← نیروگاه و پالایشگاه ← پادگان ← برجک ← پدافند هوایی ← پایانهٔ کشتیرانی ← کارخانهٔ زرهی ← فرودگاه. هر ساختمان فقط وقتی آزاد می‌شود که پیش‌نیازش ساخته شده باشد.
- **تانک‌ها و خودروهای واقعی**: هر جناح مدل‌های شاخص خودش را دارد (M1A2 آبرامز، T-90M، مرکاوا، لکلرک، آلتای، آرجون، تایپ ۹۹A، کرار) با زره، نفوذ گلوله و سرعت متفاوت.
- **هشت جناح** با ویژگی، توانایی و ساختمان ویژهٔ متفاوت (چین، ایران، ترکیه، آمریکا، روسیه، اسرائیل، هند، فرانسه).
- **سه سطح سختی** (آسان، معمولی، سخت) که اقتصاد، پدافند، اندازهٔ موج‌ها و سرعت واکنش دشمن را تغییر می‌دهد.
- **نبرد ترکیبی زمینی و هوایی**: بالگرد رزمی و جنگنده از فرودگاه بلند می‌شوند، بر فراز میدان پرواز می‌کنند و فقط پدافند هوایی، نفربر و جنگندهٔ رقیب می‌توانند گیرشان بیندازند. موشک‌های زمین‌به‌هوا و راکت‌اندازهای چندلول هم آسیب منطقه‌ای دارند.
- **دشمن با هوش مصنوعی واقعی**: هم مثل تو از صفر شروع می‌کند؛ اول مرکز فرماندهی می‌سازد، بعد نیروگاه، پالایشگاه، پادگان، پدافند هوایی، پایانهٔ کشتیرانی، کارخانهٔ زرهی و فرودگاه. ارتش را پشت پایگاه جمع می‌کند و با گروه هماهنگ حمله می‌کند و اگر پایگاهش تهدید شود مدافع می‌فرستد.
- **اقتصاد و برق**: درآمد فقط وقتی جریان دارد که مرکز فرماندهی پابرجا باشد؛ پالایشگاه و پایانهٔ کشتیرانی درآمد را بالا می‌برند و کشتیرانی سرعت تولید را ۱۲٪ زیاد می‌کند. کارخانه‌ها، پدافند و برجک‌ها برق مصرف می‌کنند و کمبود برق تولید و آتش را کند می‌کند.
- **صف تولید و زمان ساخت**: نیروها فوری ظاهر نمی‌شوند. هر پادگان و کارخانه صف خودش را دارد، نوار پیشرفت روی ساختمان دیده می‌شود و پنل انتخاب هم وضعیت صف را نشان می‌دهد.
- **مهندس کارآمد**: به‌طور خودکار نزدیک‌ترین ساختمان یا واحد آسیب‌دیدهٔ خودی را ترمیم می‌کند و خط ترمیم سبز می‌کشد.
- **زره و نفوذ**: هر واحد زره و قدرت نفوذ گلوله دارد؛ تانک سنگین در برابر آتش سبک مقاوم است، اما موشک هدایت‌شدهٔ تیم موشک‌انداز (جاولین، کورنت، اسپایک…) زره را دور می‌زند.
- **توانایی ویژهٔ جناح** با آماده‌سازی ۶۰ ثانیه‌ای؛ از تدارکات نقدی و حملهٔ هوایی تا زره واکنشی، اسکن میدان و ترمیم اضطراری.
- **خوانایی بهتر میدان**: حلقهٔ دائمی تیم (فیروزه‌ای برای شما، قرمز برای دشمن)، رنگ تیم روی نقشهٔ کوچک، نوار سلامتی روبه‌دوربین و نوار پیشرفت تولید بالای ساختمان.
- **رابط فارسی و راست‌به‌چپ** با فونت وزیرمتن (بسته‌بندی‌شده، بدون نیاز به اینترنت)، صفحهٔ راهنما، آمار پایان نبرد، سطح سختی، صداهای ساخته‌شده با Web Audio و دکمهٔ خاموش‌کردن صدا.
- **کنترل موبایل**: لمس برای انتخاب و فرمان، کشیدن برای جابه‌جایی دوربین، دو انگشت برای بزرگ‌نمایی و کشیدن روی نقشهٔ کوچک.

## اجرا در رایانه

```bash
npm install
npm run dev
```

Vite نشانی محلی را نشان می‌دهد. برای ساخت نسخهٔ انتشار:

```bash
npm run build
```

خروجی آمادهٔ انتشار در پوشهٔ `dist/` ساخته می‌شود.

## انتشار رایگان با GitHub و Cloudflare Pages

1. این پوشه را به یک مخزن GitHub جدید push کنید.
2. در Cloudflare از **Workers & Pages → Create → Pages → Connect to Git** مخزن را انتخاب کنید.
3. فرمان ساخت را `npm run build` و پوشهٔ خروجی را `dist` بگذارید؛ نسخهٔ Node را روی `20` تنظیم کنید.
4. بعد از Deploy، هر push به شاخهٔ اصلی به‌صورت خودکار نسخهٔ تازه را منتشر می‌کند.

این نسخه کاملاً سمت کاربر است و سرور یا کلید API ندارد؛ بنابراین برای نسخهٔ تک‌نفره نیازی به سرویس پولی نیست. چندنفرهٔ آنلاین، ذخیرهٔ ابری و حساب کاربری در این نمونه پیاده‌سازی نشده‌اند.

## مکانیک‌های بازی

### اقتصاد
- درآمد پایه ۲۰ اعتبار در ثانیه، فقط با وجود مرکز فرماندهی؛ هر پالایشگاه ۱۲+ و هر پایانهٔ کشتیرانی ۸+ اعتبار.
- پایانهٔ کشتیرانی سرعت تولید را ۱۲٪ (تا ۳۶٪) افزایش می‌دهد.
- ساختمان ویژهٔ چین و هند درآمد بیشتری می‌دهد؛ هند ۱۸٪ درآمد بیشتر دارد.
- ساخت و تولید هزینهٔ فوری می‌گیرد؛ صف تولید تا چهار نیرو در هر ساختمان.
- اگر پیش‌نیاز یک ساختمان از بین برود، ساخت آن دوباره قفل می‌شود؛ پس پدافند و ساختمان‌های کلیدی را حفظ کن.

### برق
- هر نیروگاه ۱۶۰ برق تولید می‌کند؛ مزرعهٔ خورشیدی هند ۹۵ برق.
- مصرف: پادگان ۲۰، کارخانهٔ زرهی ۵۵، برجک ۲۰، پدافند هوایی ۳۰، پالایشگاه ۲۵، پایانهٔ کشتیرانی ۳۵، فرودگاه ۶۰ و ساختمان ویژه ۲۸ تا ۴۵.
- اگر مصرف از تولید بیشتر شود، سرعت تولید و شلیک برجک‌ها و درآمد پایگاه کم می‌شود و هشدار می‌گیری.

### ترمیم و پدافند
- مهندس در حالت بی‌حرکت، ساختمان‌ها و واحدهای آسیب‌دیدهٔ نزدیک را ترمیم می‌کند.
- برجک دفاعی برد ۱۴ و مرکز فرماندهی برد ۱۲ دارند و فقط اهداف زمینی را می‌زنند.
- سامانهٔ پدافند هوایی برد ۲۴ دارد، فقط بالگرد و جنگنده را هدف می‌گیرد و آسیب سنگینی می‌زند؛ بدون آن، بمباران هوایی دشمن پایگاه را می‌شکند.
- نفربرها می‌توانند به هوا شلیک کنند؛ سایر واحدهای زمینی نمی‌توانند.
- راکت‌انداز چندلول آسیب منطقه‌ای دارد و برای شکستن صفوف دشمن ساخته شده است.
- واحدهای در حالت پدافند، دشمن را در برد سلاح خود می‌زنند ولی دنبالش نمی‌روند.

### هوش مصنوعی دشمن
- اقتصاد مستقل با درآمد و ذخیرهٔ اعتبار، از صفر و با همان ۶٬۰۰۰ اعتبار اولیه.
- همان زنجیرهٔ پیشرفت را می‌سازد: مرکز فرماندهی، نیروگاه، پالایشگاه، پادگان، برجک، پدافند هوایی، پایانهٔ کشتیرانی، کارخانهٔ زرهی و فرودگاه.
- جمع‌کردن نیرو در نقطهٔ تجمع و سپس حملهٔ گروهی به نزدیک‌ترین ساختمان شما.
- ترکیب نیروها با گذشت زمان بهتر می‌شود (گشتی و موشک‌انداز ← تانک و نفربر ← بالگرد و جنگنده) و روی سطح سخت سریع‌تر و بزرگ‌تر می‌شود.
- اگر واحدهای شما به پایگاهش نزدیک شوند، مدافع‌ها را روی مهاجم می‌فرستد.

### پایان بازی
- نابودکردن مرکز فرماندهی دشمن = پیروزی؛ از دست‌دادن مرکز فرماندهی خودی = شکست.
- صفحهٔ پایان، زمان نبرد، تعداد اهداف منهدم‌شده و تلفات را نشان می‌دهد و امکان شروع دوباره یا تغییر جناح را می‌دهد.

## برای توسعه

- کل منطق بازی در `src/main.js` و ظاهر در `src/style.css` است.
- در کنسول مرورگر می‌توانی با `window.__frontline.snapshot()` وضعیت لحظه‌ای بازی (اعتبار، برق، ساختمان‌ها، صف‌ها، آمار) را ببینی. برای آزمایش سریع، `window.__frontline.grant(10000)` اعتبار می‌دهد و `window.__frontline.build('hq', -24, -14)` ساختمان می‌سازد.
- داده‌های جناح‌ها، ساختمان‌ها و واحدها در بالای `src/main.js` متمرکز است؛ تغییر هزینه، سلامتی، برد و زمان ساخت از همان‌جا انجام می‌شود.

## محدودهٔ نمونه

نام کشورها و مدل‌های تجهیزات برای هویت و حال‌وهوای واقع‌گرایانه در یک بازی خیالی استفاده شده‌اند؛ مدل‌های سه‌بعدی، نمایشی و ساده‌شده‌اند و بازآفرینی دقیق تجهیزات واقعی نیستند. بازی تک‌نفره است و ذخیرهٔ بازی، چندنفرهٔ آنلاین و نقشهٔ چندگانه ندارد.
