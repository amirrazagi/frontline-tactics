# Frontline Tactics — نبرد فرماندهان

یک بازی استراتژی هم‌زمان (RTS) سه‌بعدی و تک‌نفره برای مرورگر؛ ساخته‌شده با Three.js و Vite. همهٔ مدل‌های میدان در خود برنامه و با هندسه‌های ساده ساخته می‌شوند و بازی به هیچ فایل گرافیکی یا صدای خارجی وابسته نیست.

## چه چیزهایی در بازی هست

- **هشت جناح** با ویژگی، توانایی و ساختمان ویژهٔ متفاوت (چین، ایران، ترکیه، آمریکا، روسیه، اسرائیل، هند، فرانسه).
- **سه سطح سختی** (آسان، معمولی، سخت) که اقتصاد، پدافند، اندازهٔ موج‌ها و سرعت واکنش دشمن را تغییر می‌دهد.
- **دشمن با هوش مصنوعی واقعی**: درآمد و خرج دارد، نیروگاه و پالایشگاه می‌سازد، برجک دفاعی می‌چیند، ارتش را پشت پایگاه جمع می‌کند و بعد با یک گروه هماهنگ حمله می‌کند. اگر پایگاهش را تهدید کنی، مدافع‌ها را می‌فرستد.
- **اقتصاد و برق**: اعتبار از درآمد دوره‌ای و پالایشگاه‌ها به دست می‌آید؛ کارخانه‌ها، برجک‌ها و رادارها برق مصرف می‌کنند. کمبود برق تولید و آتش برجک‌ها را کند می‌کند و درآمد را کاهش می‌دهد.
- **صف تولید و زمان ساخت**: نیروها فوری ظاهر نمی‌شوند. هر پادگان و کارخانه صف خودش را دارد، نوار پیشرفت روی ساختمان دیده می‌شود و پنل انتخاب هم وضعیت صف را نشان می‌دهد.
- **مهندس کارآمد**: به‌طور خودکار نزدیک‌ترین ساختمان یا واحد آسیب‌دیدهٔ خودی را ترمیم می‌کند و خط ترمیم سبز می‌کشد.
- **توانایی ویژهٔ جناح** با آماده‌سازی ۶۰ ثانیه‌ای؛ از تدارکات نقدی و حملهٔ هوایی تا زره واکنشی، اسکن میدان و ترمیم اضطراری.
- **خوانایی بهتر میدان**: حلقهٔ دائمی تیم (فیروزه‌ای برای شما، قرمز برای دشمن)، رنگ تیم روی نقشهٔ کوچک، نوار سلامتی روبه‌دوربین و نوار پیشرفت تولید بالای ساختمان.
- **رابط فارسی و راست‌به‌چپ** با فونت وزیرمتن (بسته‌بندی‌شده، بدون نیاز به اینترنت)، صفحهٔ راهنما، آمار پایان نبرد، سطح سختی، صداهای ساخته‌شده با Web Audio و دکمهٔ خاموش‌کردن صدا.
- **کنترل موبایل**: لمس برای انتخاب و فرمان، کشیدن برای جابه‌جایی دوربین، دو انگشت برای بزرگ‌نمایی و کشیدن روی نقشهٔ کوچک.

## اجرا در رایانه

```bash
npm install
npm run dev
```

Vite نشانی محلی را نشان می‌دهد. برای ساخت نسخهٔ انتشار:

```bash
npm run build
```

خروجی آمادهٔ انتشار در پوشهٔ `dist/` ساخته می‌شود.

## انتشار رایگان با GitHub و Cloudflare Pages

1. این پوشه را به یک مخزن GitHub جدید push کنید.
2. در Cloudflare از **Workers & Pages → Create → Pages → Connect to Git** مخزن را انتخاب کنید.
3. فرمان ساخت را `npm run build` و پوشهٔ خروجی را `dist` بگذارید؛ نسخهٔ Node را روی `20` تنظیم کنید.
4. بعد از Deploy، هر push به شاخهٔ اصلی به‌صورت خودکار نسخهٔ تازه را منتشر می‌کند.

این نسخه کاملاً سمت کاربر است و سرور یا کلید API ندارد؛ بنابراین برای نسخهٔ تک‌نفره نیازی به سرویس پولی نیست. چندنفرهٔ آنلاین، ذخیرهٔ ابری و حساب کاربری در این نمونه پیاده‌سازی نشده‌اند.

## کنترل‌ها

| فرمان | روش |
| --- | --- |
| انتخاب واحد یا ساختمان | کلیک/لمس |
| حرکت واحد انتخاب‌شده | کلیک/لمس روی زمین |
| حمله | کلیک روی دشمن با واحد رزمی انتخاب‌شده |
| فرمان به همهٔ نیروها | کلیک راست روی زمین یا دشمن |
| ساخت‌وساز | تب «ساخت‌وساز» ← انتخاب گزینه ← کلیک روی نقطهٔ سبز |
| تولید نیرو | تب «تولید نیرو» ← انتخاب واحد (به صف می‌رود) |
| پدافند در جای خود | انتخاب واحد ← «توقف و پدافند» |
| توانایی ویژه | دکمهٔ توانایی در کارت جناح |
| دوربین | کشیدن میدان، کلیدهای W A S D یا جهت‌ها، نقشهٔ کوچک |
| بزرگ‌نمایی | چرخ ماوس، کلید + و −، یا دو انگشت |
| بازگشت به پایگاه | `H` |
| توقف/ادامهٔ بازی | `Space` یا دکمهٔ مکث |
| لغو ساخت یا هدف‌گیری | `Esc` |

## مکانیک‌های بازی

### اقتصاد
- درآمد پایه ۱۸ اعتبار در ثانیه، به‌علاوهٔ ۹ اعتبار برای هر پالایشگاه.
- ساختمان ویژهٔ چین و هند درآمد بیشتری می‌دهد؛ هند ۱۸٪ درآمد بیشتر دارد.
- ساخت و تولید هزینهٔ فوری می‌گیرد؛ صف تولید تا چهار نیرو در هر ساختمان.

### برق
- هر نیروگاه ۱۳۰ برق تولید می‌کند؛ مزرعهٔ خورشیدی هند ۹۵ برق.
- مصرف: پادگان ۲۲، کارخانه ۴۲، برجک ۲۴، پالایشگاه ۲۶، رادار ۲۴ و ساختمان ویژه ۳۰ تا ۴۵.
- اگر مصرف از تولید بیشتر شود، سرعت تولید و شلیک برجک‌ها و درآمد پایگاه کم می‌شود و هشدار می‌گیری.

### ترمیم و پدافند
- مهندس در حالت بی‌حرکت، ساختمان‌ها و واحدهای آسیب‌دیدهٔ نزدیک را ترمیم می‌کند.
- برجک دفاعی برد ۱۳ و مرکز فرماندهی برد ۱۱٫۵ دارد؛ توپخانه با برد ۱۵ می‌تواند از بیرون بزند، اما شکننده است و به محافظ نیاز دارد.
- واحدهای در حالت پدافند، دشمن را در برد سلاح خود می‌زنند ولی دنبالش نمی‌روند.

### هوش مصنوعی دشمن
- اقتصاد مستقل با درآمد و ذخیرهٔ اعتبار.
- ساخت نیروگاه، پالایشگاه، برجک، پادگان و کارخانه با اولویت‌بندی.
- جمع‌کردن نیرو در نقطهٔ تجمع و سپس حملهٔ گروهی به نزدیک‌ترین ساختمان شما.
- ترکیب نیروها با گذشت زمان بهتر می‌شود (گشتی ← تانک ← توپخانه) و روی سطح سخت سریع‌تر و بزرگ‌تر می‌شود.
- اگر واحدهای شما به پایگاهش نزدیک شوند، مدافع‌ها را روی مهاجم می‌فرستد.

### پایان بازی
- نابودکردن مرکز فرماندهی دشمن = پیروزی؛ از دست‌دادن مرکز فرماندهی خودی = شکست.
- صفحهٔ پایان، زمان نبرد، تعداد اهداف منهدم‌شده و تلفات را نشان می‌دهد و امکان شروع دوباره یا تغییر جناح را می‌دهد.

## برای توسعه

- کل منطق بازی در `src/main.js` و ظاهر در `src/style.css` است.
- در کنسول مرورگر می‌توانی با `window.__frontline.snapshot()` وضعیت لحظه‌ای بازی (اعتبار، برق، ساختمان‌ها، صف‌ها، آمار) را ببینی.
- داده‌های جناح‌ها، ساختمان‌ها و واحدها در بالای `src/main.js` متمرکز است؛ تغییر هزینه، سلامتی، برد و زمان ساخت از همان‌جا انجام می‌شود.

## محدودهٔ نمونه

نام کشورها فقط برای هویت جناح‌های یک بازی خیالی استفاده شده است؛ نشان‌ها، واحدها و توانایی‌ها بازآفرینیِ تجهیزات یا عملیات واقعی نیستند. بازی تک‌نفره است و ذخیرهٔ بازی، چندنفرهٔ آنلاین و نقشهٔ چندگانه ندارد.
