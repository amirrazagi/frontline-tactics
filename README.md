# Frontline Tactics — نبرد فرماندهان

یک نمونهٔ اولیهٔ RTS سه‌بعدی و تک‌نفره برای مرورگر؛ ساخته‌شده با Three.js و Vite. همهٔ مدل‌های میدان در خود برنامه و با هندسه‌های ساده ساخته می‌شوند و به فایل گرافیکی خارجی وابسته نیستند.

## اجرا در رایانه

```bash
npm install
npm run dev
```

Vite نشانی محلی را نشان می‌دهد. برای ساخت نسخهٔ انتشار:

```bash
npm run build
```

خروجی آمادهٔ انتشار در پوشهٔ `dist/` ساخته می‌شود.

## انتشار رایگان با GitHub و Cloudflare Pages

1. این پوشه را به یک مخزن GitHub جدید push کنید.
2. در Cloudflare از **Workers & Pages → Create → Pages → Connect to Git** مخزن را انتخاب کنید.
3. فرمان ساخت را `npm run build` و پوشهٔ خروجی را `dist` بگذارید؛ نسخهٔ Node را روی `20` تنظیم کنید.
4. بعد از Deploy، هر push به شاخهٔ اصلی به‌صورت خودکار نسخهٔ تازه را منتشر می‌کند.

این نسخه کاملاً سمت کاربر است و سرور یا کلید API ندارد؛ بنابراین برای نسخهٔ تک‌نفره نیازی به سرویس پولی نیست. چندنفرهٔ آنلاین، ذخیرهٔ ابری و حساب کاربری در این نمونه پیاده‌سازی نشده‌اند.

## کنترل‌ها

- انتخاب واحد/ساختمان: کلیک یا لمس
- حرکت: انتخاب واحد و کلیک/لمس روی زمین
- حمله: انتخاب واحد و کلیک روی دشمن؛ کلیک راست هم پشتیبانی می‌شود
- دوربین: کشیدن میدان یا انتخاب نقطه روی نقشهٔ کوچک
- ساخت: انتخاب «ساخت‌وساز»، بعد کلیک/لمس روی نقطهٔ سبزِ مجاز
- `Esc`: لغو حالت ساخت یا توانایی هدف‌دار

## محدودهٔ نمونه

هشت جناح با ویژگی‌های بازیِ متعادل‌شده، چند ساختمان و واحد، منابع، موج‌های دشمن، توانایی ویژه و شرط پیروزی/شکست در نظر گرفته شده‌اند. نام کشورها فقط برای هویت جناح‌های یک بازی خیالی استفاده شده است؛ نشان‌ها، واحدها و توانایی‌ها بازآفرینیِ تجهیزات یا عملیات واقعی نیستند. می‌توان فهرست جناح‌ها و محتوای بازی را بعداً گسترش داد.
